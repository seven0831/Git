# 校园活动机会平台规范文档（Spec-Driven Development）

> 本文档是项目的唯一事实来源（Source of Truth）。所有代码实现必须与本文档保持一致；当需求变更时，先修改本文档，再修改代码。

## 1. 项目概述

一个**纯前端的校园活动机会平台**，面向在校大学新生：浏览校园活动（竞赛、讲座分享、学习小组、招募、学生自发、通知），查看即将截止报名的活动，支持学生自己发布活动、收藏感兴趣的活动。所有数据持久化在浏览器 localStorage 中。

- 运行形态：纯静态多页面网站（HTML + CSS + JavaScript，无后端、无构建、无第三方依赖）
- 界面语言：中文
- 数据：`activities.json` 初始 26 条活动 + localStorage 持久化（含学生新发布的活动与收藏）

## 2. 目标与非目标

### 2.1 目标（本版本范围，对应考核 9 条标准 + 收藏扩展）

1. **4 个页面互相导航**：`index.html`（首页）、`list.html`（活动列表筛选页）、`detail.html`（活动详情页）、`publish.html`（学生发布表单页）。
2. **首页**：顶部导航（跳转列表/发布）；项目标题"校园活动机会平台，面向在校大学新生"；【即将截止报名】板块自动筛选 3 天以内报名截止的活动，卡片高亮展示；过期结束的活动标记"已结束"，不再推荐。
3. **列表页**：顶部导航；按类别筛选（竞赛、讲座分享、学习小组、招募、学生自发、通知）；支持按报名截止日期排序；活动卡片展示标题、活动类型、开展时间、报名截止时间、面向对象；点击卡片跳转详情页并传递活动 id。
4. **详情页**：展示单条活动全部信息：编号、活动名称、举办时间、报名截止时间、面向对象、地点、内容简介。
5. **发布页**：表单（活动名称、活动分类、举办时间、报名截止日期、面向人群、地点、活动简介）；提交时表单校验；提交后存入 localStorage；成功弹窗提示；新活动加入全局活动库，列表页可见。
6. **初始数据**：`activities.json` 26 条活动；页面加载时读取，localStorage 为空则写入初始化数据。
7. **收藏功能**：列表卡片与详情页提供收藏按钮（toggle）；"我的收藏"可一键筛选收藏的活动；收藏持久化。

### 2.2 非目标（本版本不实现）

- 后端服务、账号体系、真实多用户。
- 活动报名/取消报名流程。
- 图片上传、富文本编辑。
- 关键词搜索（列表页仅按类别与截止时间筛选排序）。
- 移动端 App。

## 3. 术语与领域模型

| 术语 | 英文标识 | 说明 |
| --- | --- | --- |
| 活动 | Activity | 一条校园活动信息 |
| 类别 | category | 竞赛 / 讲座分享 / 学习小组 / 招募 / 学生自发 / 通知 |
| 报名截止时间 | deadline | 字符串，可能含日期时间、多个节点或"满员即止/未注明"等 |
| 收藏 | Favorite | 本机用户对活动的标记，存 localStorage 数组 |

**活动字段**：`id`、`name`（名称）、`category`（分类）、`holdTime`（举办时间）、`deadline`（报名截止时间）、`audience`（面向对象）、`place`（地点，可缺省）、`remark`（内容简介）。

## 4. 功能需求

### 4.1 通用导航

每个页面顶部导航栏：平台名（回首页）、活动列表、发布活动、我的收藏（列表页收藏筛选视图）。

### 4.2 首页（index.html）

- 顶部导航栏。
- 主体标题：**校园活动机会平台**，副标题"面向在校大学新生"。
- 【即将截止报名】板块：自动筛选"报名截止时间在未来 3 天以内（含今天）"的活动，以高亮卡片展示（"⏰ 即将截止"徽标 + 剩余时间）。
- 【更多活动】板块：按发布时间展示全部活动（过期活动显示灰色"已结束"徽标）。
- 已过期的活动**不再推荐**（不进入"即将截止报名"板块）。

**业务规则：**
- "3 天以内"：`now <= deadline <= now + 3 天`。
- 已结束：`deadline < now`。
- `deadline` 无法解析为日期（"满员即止"、"未注明"、"长期招募"等）视为"无明确截止时间"，不进入即将截止板块，不标记已结束。

### 4.3 列表页（list.html）

- 顶部导航。
- 筛选控件：类别按钮（全部 + 6 类）；"我的收藏"筛选按钮。
- 排序：默认按 id 顺序；"按截止时间排序"按钮切换为截止时间升序（无法解析的排在最后）。
- 活动卡片：标题、活动类型徽标、开展时间、报名截止时间、面向对象；卡片含收藏按钮（♥ toggle）；过期活动显示"已结束"徽标并降灰。
- 点击卡片跳转 `detail.html?id=<活动id>`。

**业务规则：**
- 筛选与排序可叠加（收藏筛选 + 类别筛选 + 排序）。
- 收藏按钮点击不触发跳转。

### 4.4 详情页（detail.html）

- 通过 URL 参数 `?id=` 定位活动。
- 展示：编号（id）、活动名称、举办时间、报名截止时间、面向对象、地点（缺省显示"未注明"）、内容简介。
- 收藏按钮（toggle）、返回列表按钮。
- 活动不存在时显示友好提示。

### 4.5 发布页（publish.html）

- 表单字段：活动名称、活动分类（下拉 6 类）、举办时间、报名截止日期（datetime-local）、面向人群、地点、活动简介（textarea）。
- 提交校验：名称 1–50 字、分类必选、举办时间必填、报名截止必填且不得早于当前时间、面向人群必填、简介 1–500 字；地点可选（缺省"未注明"）。校验失败在对应字段旁提示，不提交。
- 提交成功：活动写入 localStorage（分配自增 id），弹出成功弹窗（含"去列表页查看"按钮），活动加入全局活动库。

### 4.6 初始数据（activities.json）

- 26 条活动（与考核要求完全一致），首次加载（localStorage 为空）时写入 localStorage。
- 学生新发布的活动追加到 localStorage，刷新后保留。
- 活动数据读取顺序：localStorage 有数据用 localStorage；否则读取 `activities.json` 并初始化。

### 4.7 收藏

- 收藏存储：localStorage `eventFavorites`（活动 id 数组）。
- 入口：首页/列表页卡片 ♡ 按钮、详情页收藏按钮；再次点击取消收藏。
- 查看：导航"我的收藏"（列表页 `?fav=1`）+ 列表页"我的收藏"筛选按钮。
- 收藏持久化，刷新保留；收藏不存在的 id 自动忽略。

## 5. 数据模型（localStorage）

| 键 | 内容 | 说明 |
| --- | --- | --- |
| `eventActivities` | 活动数组 | 结构同 `activities.json`；首次使用从 json 初始化 |
| `eventFavorites` | id 数组 | 收藏的活动 id，如 `[3, 7, 14]` |
| `eventSeq` | 整数 | 自增 id 序列（初始化 = json 中最大 id） |

**activities.json 单条结构：**

```json
{ "id": 1, "name": "…", "category": "竞赛", "holdTime": "…", "deadline": "…", "audience": "…", "place": "…(可缺省)", "remark": "…" }
```

**截止时间解析规则**（字符串 → Date）：
- 兼容全角/特殊连字符（`‑` U+2011、`–`）替换为 `-`。
- 取第一个 `YYYY-MM-DD [HH:mm]` 模式（如"2026-09-21 18:00(意向登记),…"取首个节点）。
- 无时间部分默认补 `23:59`。
- 无法匹配 → `null`（无明确截止时间）。

## 6. 数据层接口规范（common.js）

> 所有页面通过 `db` 模块访问数据，不直接操作 localStorage。

| 函数 | 说明 |
| --- | --- |
| `db.init()` | 异步初始化：localStorage 为空时 fetch `activities.json` 写入；返回活动数组 |
| `db.getActivities()` | 返回全部活动数组 |
| `db.getActivity(id)` | 按 id 查询，不存在返回 `null` |
| `db.addActivity(data)` | 校验后写入（分配自增 id），返回新活动 |
| `db.parseDeadline(str)` | 截止时间字符串 → `Date | null`（按 §5 规则） |
| `db.statusOf(activity)` | `'expired'`（已结束）/ `'urgent'`（3 天内截止）/ `'open'` / `'unknown'`（无法解析） |
| `db.getUrgent()` | 返回 `status === 'urgent'` 的活动（按截止时间升序） |
| `db.isFavorite(id)` / `db.toggleFavorite(id)` / `db.getFavoriteIds()` | 收藏查询与 toggle |
| `db.CATEGORIES` | 6 个类别常量 |

## 7. 页面与交互

### 7.1 视觉

- 共享 `styles.css`；主色蓝（校园感），"即将截止"橙红色徽标、"已结束"灰色徽标、收藏红心。
- 卡片：白底圆角 + 轻阴影；hover 提升。

### 7.2 各页行为

- **首页**：加载后渲染"即将截止报名"（高亮卡片，最多 6 条）与"更多活动"（全部，含已结束标记）两个板块。
- **列表页**：状态保存在 URL query（`?cat=竞赛&fav=1&sort=deadline`），刷新/分享可保持筛选状态；卡片点击跳详情。
- **详情页**：URL `?id=N` 渲染；收藏按钮即时更新。
- **发布页**：提交后弹成功窗，清空表单；"去列表页查看"跳 `list.html`。

### 7.3 通用

- 所有渲染函数做 HTML 转义（防 XSS）。
- 空状态友好提示（如"暂无符合条件的活动"）。

## 8. 非功能需求

1. **零依赖**：原生 HTML/CSS/JS；`activities.json` 通过 fetch 读取（需通过 http 访问，或本地静态服务器）。
2. **持久化**：活动库与收藏均存 localStorage；数据变更立即写入。
3. **校验**：发布表单前端校验 + 数据层二次校验；中文错误提示。
4. **容错**：localStorage JSON 解析失败回退重建；`activities.json` 读取失败降级为空库并提示。
5. **可维护性**：数据层（common.js）与页面脚本分离；样式共享。

## 11. 验收标准（考核 9 条 + 收藏）

1. 4 个页面存在且顶部导航可互相跳转。
2. 首页有项目标题；【即将截止报名】板块自动筛选 3 天内截止的活动并高亮；过期活动标记"已结束"且不推荐。
3. 列表页可按 6 个类别筛选；可按报名截止日期排序；卡片展示标题/类型/开展时间/截止时间/面向对象；点击跳详情并传 id。
4. 详情页展示编号、名称、举办时间、报名截止时间、面向对象、地点、简介。
5. 发布页表单校验通过后写入 localStorage，成功弹窗提示，列表页可见新活动，刷新保留。
6. `activities.json` 26 条数据完整；localStorage 为空时自动初始化。
7. 收藏按钮可收藏/取消收藏；"我的收藏"筛选只显示已收藏活动；刷新后收藏保留。
8. 浏览器控制台无报错；全部验收逐条走查通过。
