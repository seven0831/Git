# 校园交流平台

纯前端的校园交流社区：只用 HTML + CSS + JavaScript 实现，无后端、无依赖、无构建步骤。

## 使用方法

双击打开 `index.html` 即可使用（首次打开会要求设置昵称）。

> 数据保存在浏览器 localStorage 中：换浏览器、换设备或清除浏览器数据会导致内容丢失。

## 功能

- **板块浏览**：综合论坛、约球、学习交流、项目组队、兴趣活动
- **发帖**：标题 + 正文 + 外链图片（最多 9 张）
- **互动**：评论、回复（回复 @某人）、点赞（帖子与评论均可）
- **浏览**：板块筛选、关键词搜索、最新/最热排序、分页
- **管理**：编辑/删除自己的帖子与评论

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架（导航、视图容器、弹窗） |
| `styles.css` | 全部样式 |
| `store.js` | 数据层：localStorage 读写、校验、统计 |
| `app.js` | UI 层：hash 路由、视图渲染、事件绑定 |
| `docs/SPEC.md` | 规范文档（Source of Truth） |
| `docs/TASKS.md` | 任务分解与依赖关系 |

## 开发说明

- 路由：hash 路由（`#/` 列表页、`#/post/:id` 详情页）
- 修改需求时请先更新 `docs/SPEC.md`，再改代码
