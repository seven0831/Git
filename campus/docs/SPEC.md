# 校园交流平台规范文档（Spec-Driven Development）

> 本文档是项目的唯一事实来源（Source of Truth）。所有代码实现必须与本文档保持一致；当需求变更时，先修改本文档，再修改代码。

## 1. 项目概述

一个**纯前端的校园交流社区网页**：只用 HTML + CSS + JavaScript 实现，无后端、无构建工具、无第三方依赖，浏览器直接打开即可使用。用户在预设板块（论坛、约球、学习交流、项目组队、兴趣活动）中发帖交流、评论互动与点赞。所有数据持久化在浏览器 localStorage 中。

- 运行形态：纯静态网页（双击 `index.html` 即可打开，或任意静态服务器托管）
- 界面语言：中文
- 用户体系：免登录，首次使用时设置昵称

## 2. 目标与非目标

### 2.1 目标（本版本范围）

1. **昵称设置**：首次打开设置昵称（本机生成固定用户 ID），之后可随时修改；所有内容署名该昵称。
2. **板块浏览**：固定 5 个板块（综合论坛、约球、学习交流、项目组队、兴趣活动），按板块浏览帖子。
3. **发帖互动**：发帖（标题 + 正文 + 可选外链图片）、编辑、删除；列表支持板块筛选、关键词搜索、最新/最热排序、分页。
4. **评论与点赞**：帖子下发表评论、回复他人评论（一级引用）、删除；帖子与评论均可点赞/取消点赞。
5. **新生推荐**：学习交流、项目组队板块的帖子可标记"适合大一新生"；列表页通过开关一键筛选此类内容。

### 2.2 非目标（本版本不实现）

- 后端服务与数据库（数据仅存本机浏览器 localStorage）。
- 真实多用户与账号体系（本机只有一个昵称身份）。
- 图片文件上传（仅支持外链图片 URL 展示）。
- 管理员角色与内容审核。
- 板块自定义创建（本期板块固定）。
- 私信、通知、用户主页与关注。
- 新生推荐标签的关键词自动识别（标记由发帖人手动勾选）。
- 移动端 App / 桌面客户端。

> 以上非目标可作为后续版本迭代项，但当前版本不纳入实现与验收。

## 3. 术语与领域模型

| 术语 | 英文标识 | 说明 |
| --- | --- | --- |
| 本机用户 | local user | 本浏览器唯一的身份，含固定 ID 与昵称，存 localStorage |
| 板块 | Board | 帖子所属的固定分类，共 5 个，代码内常量 |
| 帖子 | Post | 用户发布的主题内容，含标题、正文、外链图片 |
| 评论 | Comment | 帖子下的回复，可引用另一条评论表示"回复某人" |
| 点赞 | Like | 本机用户对帖子或评论的一次点赞（可取消） |
| 新生推荐 | freshman_friendly | 帖子上的布尔标记，表示内容适合大一零基础新生 |

**帖子是核心对象**：帖子归属某板块；评论挂在帖子下；点赞可作用于帖子或评论。

## 4. 功能需求

### 4.1 本机用户

- 首次打开应用时弹出昵称设置层：输入 1–20 字符的昵称，保存后进入主页。
- 生成固定用户 ID（`campus-` + 随机串），与昵称一起存 localStorage，此后不再变化。
- 导航栏提供"修改昵称"入口，修改后全站（含历史帖子与评论）即时显示新昵称。

**业务规则：**
- 昵称 1–20 字符，去首尾空白后校验，不能为空。
- 删除/编辑操作仅允许作用于"自己"（`author_id` 等于本机用户 ID）的内容。由于本机只有唯一身份，正常使用下所有历史内容均为自己发布。

### 4.2 板块

- 固定 5 个板块（代码内常量数组）：综合论坛、约球、学习交流、项目组队、兴趣活动。
- 列表页顶部渲染板块标签导航（"全部" + 5 个板块）。

**业务规则：**
- 板块本期不可增删改。
- 发帖时必须选择板块。

### 4.3 帖子

- 发帖：选择板块，填写标题、正文，可选外链图片（最多 9 张）；板块为学习交流或项目组队时，可勾选"适合大一新生"。
- 列表：支持按板块筛选、关键词搜索（标题 + 正文）、排序（`latest` 最新 / `hot` 最热）、分页（每页 20 条）。
- 详情：完整帖子内容 + 图片 + 点赞/评论统计。
- 编辑：可编辑自己的帖子（板块、标题、正文、图片、新生推荐标记）。
- 删除：删除自己的帖子；删除时其评论与相关点赞一并移除。

**业务规则：**
- 标题 1–50 字；正文 1–5000 字。
- 图片为外链 URL 数组，每个 URL 必须以 `http://` 或 `https://` 开头且长度 ≤ 500，数量 ≤ 9；仅做 `<img>` 展示，不做文件上传；图片加载失败显示占位。
- 热度 = 点赞数 + 评论数；`hot` 排序按热度倒序，同热度按创建时间倒序。
- 列表卡片显示 `excerpt`（正文前 100 字）与统计；详情显示全文。
- `freshman_friendly` 仅在学习交流、项目组队板块允许为 `true`；其他板块恒为 `false`（板块切换时自动清除）。
- 删除前弹确认框。

### 4.4 评论与点赞

- 评论：在帖子详情页发表评论；可引用另一条评论（`parent_id`）表示"回复 @某人"，平铺展示（不做多层嵌套）。
- 删除评论：仅自己发布的可删；删除时其下引用它的回复级联删除，相关点赞一并移除。
- 点赞：对帖子或评论点赞；再次点击取消点赞（toggle），按钮状态与数量即时更新。

**业务规则：**
- 评论内容 1–500 字。
- `parent_id` 必须指向同一帖子下的评论，否则校验失败。
- 点赞存储为对象上的 `like_user_ids` 数组（本机单用户最多含一个元素）；toggle 幂等。

### 4.5 新生推荐

- 发帖/编辑时，板块为学习交流或项目组队则显示"适合大一新生"复选框（默认不勾选）。
- 列表页提供"🎓 新生推荐"开关按钮：开启后，当前筛选结果只显示标记了新生推荐的帖子；关闭则不过滤。
- 带标记的帖子在卡片与详情页显示"🎓 新生推荐"徽标。

**业务规则：**
- 帖子切换到非支持板块时，标记自动清除（置 `false`）。
- 开关与其他筛选（板块/搜索/排序/分页）叠加生效。

## 5. 数据模型（localStorage）

> 所有数据以 JSON 字符串存储在 `localStorage`，键统一带 `campus.` 前缀。首次运行自动初始化。清除浏览器数据会导致内容丢失（见 §10）。

| 键 | 内容 | 结构 |
| --- | --- | --- |
| `campus.user` | 本机用户 | `{ id, nickname }`，`id` 形如 `campus-xxxxxxxx` |
| `campus.seq` | 自增 ID 序列 | 整数，每次创建帖子/评论时 +1 |
| `campus.posts` | 帖子数组 | `[{ id, board_id, author_id, author_name, title, content, images: [url], freshman_friendly: bool, created_at, updated_at, like_user_ids: [userId] }]` |
| `campus.comments` | 评论数组 | `[{ id, post_id, author_id, author_name, parent_id|null, content, created_at, like_user_ids: [userId] }]` |

- 时间统一存 ISO 字符串（`new Date().toISOString()`），展示时格式化为 `YYYY-MM-DD HH:mm`。
- `author_name` 为发布时的昵称快照，但展示时实时读取 `campus.user.nickname`（本机唯一身份，二者恒等）。
- 板块为代码内常量，不入库：

```js
const BOARDS = [
  { id: 1, name: '综合论坛' },
  { id: 2, name: '约球' },
  { id: 3, name: '学习交流' },
  { id: 4, name: '项目组队' },
  { id: 5, name: '兴趣活动' },
];
```

- 评论数不落库，查询时按 `post_id` 实时统计；热度 = `like_user_ids.length` + 评论数。

## 6. 数据层接口规范（store.js）

> 前端 UI 不直接操作 localStorage，统一通过 `store` 模块访问。所有写操作内部先校验再落库。

| 函数 | 说明 |
| --- | --- |
| `store.init()` | 读取/初始化 localStorage；返回 `{ user }`，首次使用 `user` 为 `null` |
| `store.setNickname(name)` | 校验并设置昵称（首次生成用户 ID）；返回 `{ user }` |
| `store.listPosts({ boardId, keyword, sort, page, pageSize, freshmanOnly })` | 筛选 + 排序 + 分页；`freshmanOnly` 为 `true` 时只返回标记了新生推荐的帖子；item 含 `excerpt`、`like_count`、`comment_count`、`liked`（本机用户是否已赞）、`freshman_friendly` |
| `store.getPost(id)` | 单帖详情（含统计），不存在返回 `null` |
| `store.createPost({ boardId, title, content, images, freshmanFriendly })` | 校验后创建（非支持板块强制 `false`），返回帖子对象 |
| `store.updatePost(id, { boardId, title, content, images, freshmanFriendly })` | 校验后更新（非支持板块强制 `false`），返回帖子对象 |
| `store.deletePost(id)` | 删除帖子 + 其评论 + 相关点赞 |
| `store.listComments(postId)` | 按创建时间升序返回评论列表（含 `like_count`、`liked`） |
| `store.addComment(postId, content, parentId)` | 校验（parentId 须同帖）后创建 |
| `store.deleteComment(id)` | 级联删除引用它的回复 |
| `store.toggleLike(targetType, targetId)` | `targetType` 为 `'post'` 或 `'comment'`；返回 `{ liked, like_count }` |

**校验失败**：写函数抛出 `Error`（中文消息），UI 捕获后弹出提示；不得写入脏数据。

## 7. 前端页面与交互

单页应用（hash 路由），共 3 个视图：

1. **帖子列表页（`#/`，默认）**
   - 顶部导航：平台名"校园交流平台"、板块标签（全部 + 5 个板块）、搜索框（回车触发）、排序切换（最新/最热）、"🎓 新生推荐"开关按钮、"发帖"按钮、当前昵称（点击弹出修改昵称）。
   - 帖子卡片：标题、板块徽标、新生推荐徽标（仅带标记的帖子）、昵称、时间、摘要、外链图片缩略（最多显示 3 张）、点赞数、评论数、点赞按钮（点击 toggle）。
   - 点击卡片标题进入详情页。
   - 分页控件（上一页/下一页 + "第 x / y 页"）。
   - 发帖弹窗：板块下拉、标题输入、正文 textarea、图片 URL 输入（可动态增删，最多 9 个）、"适合大一新生"复选框（仅板块为学习交流/项目组队时显示）。
   - 首次使用（无昵称）时强制弹出昵称设置层。

2. **帖子详情页（`#/post/:id`）**
   - 返回按钮；标题、板块、新生推荐徽标（仅带标记的帖子）、昵称、时间、正文全文、全部外链图片（加载失败显示占位）。
   - 操作按钮（作者本人可见）：编辑、删除。
   - 点赞按钮 + 点赞数、评论数。
   - 评论区：按时间顺序平铺；回复他人评论时显示"回复 @昵称"标记（平铺展示，不嵌套缩进）；每条评论可点赞、作者本人可删除。
   - 底部评论输入框；点击某评论"回复"后输入框上方显示"回复 @昵称"标签（可取消）。
   - 编辑帖子复用发帖弹窗（预填数据）。

3. **昵称设置层（弹窗）**
   - 首次打开强制显示，不可跳过；输入 1–20 字昵称保存。
   - 修改昵称时同样式弹窗，可取消。

通用：金额无；日期格式 `YYYY-MM-DD HH:mm`；所有写操作成功后刷新相关视图；校验错误弹出中文提示；外链图片 `referrerpolicy="no-referrer"` 加载。

## 8. 非功能需求

1. **零依赖**：仅原生 HTML / CSS / JavaScript，无构建步骤、无第三方库、无网络请求（外链图片除外）。
2. **数据持久化**：localStorage，写入后立即同步；读取时做 JSON 容错（解析失败回退为初始结构并重建）。
3. **校验与容错**：所有写操作先校验（长度、数量、URL 协议）；输入框前端做即时反馈。
4. **一致性**：删除帖子/评论时级联清理评论与点赞；点赞 toggle 幂等。
5. **可维护性**：数据层（store.js）与 UI 层（app.js）分离；视图渲染函数化，便于测试与扩展。

## 9. 技术架构与目录结构

```
campus/
├── index.html               # 页面骨架（导航、视图容器、弹窗）
├── styles.css               # 全部样式（无框架）
├── store.js                 # 数据层：localStorage 读写、校验、统计
├── app.js                   # UI 层：hash 路由、视图渲染、事件绑定
├── docs/
│   ├── SPEC.md
│   └── TASKS.md
└── README.md                # 使用说明
```

- 脚本加载顺序：`store.js` → `app.js`（普通 `<script>`，无模块构建）。
- 路由：hash 路由（`#/`、`#/post/:id`），监听 `hashchange`。

## 11. 验收标准

1. 双击 `index.html` 即可打开；首次使用弹出昵称设置层，设置后进入列表页；刷新页面数据仍在。
2. 板块标签可切换筛选；关键词搜索（标题/正文）正确；最新/最热排序正确；分页正确（每页 20 条）。
3. 可发帖（含外链图片）、编辑、删除自己的帖子；删除前有确认框；校验错误有中文提示。
4. 详情页正确展示全文与图片（失败占位）；可发表评论、回复评论（显示"回复 @昵称"）、删除自己的评论；删除帖子级联清理其评论与点赞。
5. 帖子与评论点赞 toggle 即时更新且刷新后保持。
6. 修改昵称后全站（含历史内容）显示新昵称。
7. 学习交流/项目组队发帖可勾选"适合大一新生"，其他板块不显示勾选项且标记恒为 false；开启"🎓 新生推荐"开关后仅显示带标记的帖子；卡片与详情显示"🎓 新生推荐"徽标。
8. 按 §11 逐条走查通过；浏览器控制台无报错。
