# 任务分解与依赖关系

> 任务严格按依赖关系排序：只有前置任务完成后才能开始后续任务。每个任务的"验收"是该任务完成的判定标准。

## 依赖图（概述）

```
T0 页面骨架 ──► T1 数据层 ──► T2 帖子列表页 ──► T3 帖子详情页 ──► T4 新生推荐标签 ──► T5 测试与整体验收
```

## 任务清单

| # | 任务 | 依赖 | 验收标准 |
| --- | --- | --- | --- |
| T0 | 页面骨架 | — | `index.html` + `styles.css` + `app.js` 载入；hash 路由可用（`#/`、`#/post/:id` 视图容器切换）；首次使用弹出昵称设置层，设置后写入 localStorage 并进入列表页 |
| T1 | 数据层 | T0 | `store.js` 按 SPEC §6 实现全部函数；localStorage 初始化/容错；校验规则生效；在控制台手工验证 CRUD 与 toggleLike |
| T2 | 帖子列表页 | T1 | 板块标签筛选、关键词搜索、最新/最热排序、分页（每页 20 条）正确；发帖弹窗可提交（校验生效）；帖子卡片展示摘要/图片/点赞评论数；删除自己帖子可用（确认框） |
| T3 | 帖子详情页 | T1 | 详情展示（全文、图片、统计）；编辑帖子复用弹窗；发表评论、回复（显示"回复 @昵称"）、删除评论；帖子与评论点赞 toggle 即时更新 |
| T4 | 新生推荐标签 | T1, T2, T3 | 学习交流/项目组队发帖可勾选"适合大一新生"，其他板块不显示勾选项；板块切换到非支持板块时标记自动清除；开关按钮开启后仅显示带标记帖子且与其他筛选叠加生效；卡片与详情显示"🎓 新生推荐"徽标 |
| T5 | 测试与整体验收 | T4 | 按 SPEC §11 逐条走查验收；浏览器控制台无报错 |

## 执行约定

- 每个任务完成后，在浏览器（或手工模拟数据）验证一次再进入下一个任务。
- 发现与 SPEC 冲突的地方，回到 SPEC 修订，再继续。
- 最终交付：可打开即用的纯前端应用 + 文档一致。
